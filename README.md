# ⏳ Calculadora de Colación

Aplicación web sencilla e intuitiva para calcular el tiempo de colación correspondiente según la hora de entrada y salida de un turno laboral.

## 🚀 Demo
Puedes probar la aplicación en vivo a través de GitHub Pages:
`https://TU-USUARIO.github.io/NOMBRE-DE-TU-REPOSITORIO/`

---

## 🛠️ Tecnologías utilizadas

- **HTML5**
- **CSS3** (Diseñado con interfaz en modo oscuro)
- **JavaScript (Vanilla)**

---

## 📋 ¿Cómo funciona?

El cálculo se basa en la duración total de la jornada diaria dentro del local:

- **Menos de 5 horas:** No corresponde tiempo de colación (0 min).
- **Entre 5 y 7.5 horas:** Corresponden **30 minutos (0:30)**.
- **Más de 7.5 horas:** Corresponde **1 hora (1:00)**.

*Nota: Soporta turnos rotativos que cruzan la medianoche (ej. de 18:00 a 02:00).*
